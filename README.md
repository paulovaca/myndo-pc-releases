# Myndo no PC — downloads

Canal **oficial** de instaladores e atualizações do **Myndo no PC** (Clica Ia LTDA). Aqui só ficam os binários;
o código-fonte é privado.

## Baixar
**[MyndoPC-Setup.exe (Windows 10/11, 64 bits) — última versão](https://github.com/paulovaca/myndo-pc-releases/releases/latest/download/MyndoPC-Setup.exe)**

O jeito mais fácil é pelo painel do seu agente: **Computador → Baixar para Windows**.

## Aviso do Windows (SmartScreen)
O instalador ainda **não tem certificado de assinatura**, então o Windows pode mostrar
**"O Windows protegeu o computador"**. Para seguir:
1. clique em **Mais informações**;
2. clique em **Executar assim mesmo**.

Baixe sempre por este endereço (ou pelo botão do painel). Instala só para o seu usuário, sem pedir administrador.

## Desinstalar
**Configurações → Aplicativos → Myndo no PC → Desinstalar**, ou **Menu Iniciar → Desinstalar Myndo no PC**.
O desinstalador fecha o programa, avisa o agente para revogar o computador, apaga a credencial e (se você
confirmar, que é o padrão) as configurações e o registro local. Suas pastas nunca são apagadas.
